# 📊 Superstore Sales Dashboard (Power BI)

## 🚀 Overview

This project showcases an **interactive Power BI dashboard** created using the popular Superstore dataset.

The dashboard provides insights into sales, profit, customer behavior, and regional performance, helping in data-driven business decision-making.

---

## 🎯 Objective

The objective of this project is to:

* Analyze sales and profit trends
* Identify top-performing products and categories
* Understand customer and regional behavior
* Visualize key business metrics effectively

---

## 🧠 Features

* Interactive dashboard with filters and slicers
* Sales and profit analysis
* Category and sub-category performance
* Region-wise and state-wise insights
* Customer segment analysis
* Time-based trend analysis (monthly/yearly)

---

## 🛠️ Tools & Technologies

* Power BI
* Superstore Dataset (CSV/Excel)
